    管理员命令

    管理员命令仅限 BOT 管理员使用，且只能私聊使用，主要用于运维和管理。

    /whosyourdaddy - 设置管理员

    默认权限
    无（仅 BOT 没有管理员时）

    用于初次启动设置管理员。成功后发送命令的账号成为 BOT 管理员。

    /whosyourdaddy

    仅首次有效

    只有 BOT 没有管理员时此命令才生效，后续再发无效。

    如需离线设置或更换管理员，见 首次配置。

    /sysinfo - 查看 BOT 信息

    查询 BOT 当前好友数、群组数、订阅数量。

    /sysinfo

    返回示例：

    当前好友数：88
当前群组数：84
当前Bilibili订阅数：207
当前Douyu订阅数：2
当前YTB订阅数：28
当前Huya订阅数：1

    /ping - 测试连通

    /ping

    返回：

    pong

    用于快速验证 BOT 是否正常响应。

    /log - 查询日志

    临时查看 BOT 日志。

    /log <条数> [-k <关键字>]

    例子

    查看最近 10 条日志：

    /log 10

    查看含 error 关键字的最近 20 条（先按关键字过滤，再按条数过滤）：

    /log 20 -k error

    /quit - 退出群聊

    退出群聊，或清除未正常退出的群的数据。

    /quit <群号> [-f]

    例子

    退出群 123456（若 BOT 不在群内则无效果）：

    /quit 123456

    退出并强制清除数据库内该群的数据（不管 BOT 是否在群内）：

    /quit 123456 -f

    何时用 -f

    强制清除用于维护数据库，当退群事件没正常触发时（如群被封、BOT 掉线期间被踢）。如果 BOT 持续向不存在的群发数据，可能导致封号。

    /mode - 设置运行模式

    模式 好友申请 加群邀请
    公开 自动同意 自动同意
    私人 自动拒绝 自动拒绝
    审核 保留待审 保留待审

    例子

    查看当前模式：

    /mode

    切换到私人模式：

    /mode 私人

    切换到审核模式：

    /mode 审核

    切换回公开模式：

    /mode 公开

    审核模式

    审核模式下用 /好友申请 和 /群邀请 命令管理待审请求。注意：群人数较少时加群邀请可能被系统自动同意，无法拒绝。

    /好友申请 - 管理好友申请

    审核模式下管理好友申请（需 BOT QQ 的加好友权限设为「需要审核」）。

    /好友申请                          # 查看当前申请
/好友申请 <ID>                     # 同意指定申请
/好友申请 --reject <ID>            # 拒绝指定申请
/好友申请 --all                    # 同意全部
/好友申请 --all --reject           # 拒绝全部

    申请 ID 会在查看申请时展示。

    /群邀请 - 管理群邀请

    审核模式下管理群邀请，用法与 /好友申请 大致相同：

    /群邀请                            # 查看
/群邀请 <ID>                       # 同意
/群邀请 --reject <ID>              # 拒绝
/群邀请 --all                      # 同意全部
/群邀请 --all --reject             # 拒绝全部

    存在自动同意的情况

    并非所有群邀请都可以管理，部分会被系统自动同意。

    /silence - 沉默模式

    管理员私聊可设置全局或指定群的沉默模式：

    /silence                  # 全局开启
/silence -g 123456        # 对群 123456 开启
/silence -d               # 全局关闭
/silence -d -g 123456     # 关闭群 123456

    详见 权限命令 - silence。

    /admin - 查看管理员

    /admin

    显示所有拥有 Admin 权限的人。

    /检测异常订阅 - 检查异常订阅

    默认权限
    BOT 管理员

    由于一些情况无法正常退出 Q 群（群被封、BOT 离线期间被踢），BOT 会向不存在的群推送，增加不稳定。

    此命令查询是否存在「有订阅但 BOT 不在群内」的情况：

    /检测异常订阅

    /清除订阅 - 清除订阅

    默认权限
    BOT 管理员

    清除异常订阅，或清除指定群的订阅，可指定网站和种类。

    清除订阅无法撤销

    清除后需重新订阅。

    例子

    清除异常订阅：

    /清除订阅 --abnormal

    清除异常的 bilibili 订阅：

    /清除订阅 --abnormal --site bilibili

    清除异常的 bilibili 直播订阅：

    /清除订阅 --abnormal --site bilibili --type live

    清除异常的直播订阅（所有网站）：

    /清除订阅 --abnormal --type live

    清除群 123456 和 223456 的订阅：

    /清除订阅 -g 123456,223456

    清除指定群的 bilibili 直播订阅：

    /清除订阅 -g 123456,223456 --site bilibili --type live

    /disable --global 与 /enable --global - 全局启停命令

    全局控制命令的启停，对所有群生效。

    /disable --global <命令>     # 全局禁用
/enable --global <命令>      # 全局启用

    例子

    全局禁用 help：

    /disable --global help

    全局禁用 watch：

    /disable --global watch

    全局启用 watch：

    /enable --global watch

    不覆盖单群设置

    全局禁用后所有群都不能用；再次全局启用时，恢复各群原有设置（A 群禁用、B 群启用各自保留）。

    /退订更新 - 关闭更新通知

    DDBOT 每 24 小时检查一次新版本，有更新会私聊通知管理员。不想接收可关闭：

    /退订更新
