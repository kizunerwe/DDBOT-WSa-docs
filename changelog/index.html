    更新日志

    DDBOT-WSa 的版本更新记录。原始记录来自仓库 UPDATE.md。

    WSa 分支

    2025-06-02 0.4.0 (Wsa)

    • 剔除 CQ 码，改为 array 方式发送消息
    • Lagrange 文件消息兼容
    • 支持 Twitter 订阅
    • 支持 Twitter 多个镜像源
    • 支持 Twitter 镜像的 m3u8 视频推送（需自行准备 ffmpeg）
    • 兼容 Youtube 新、老 ID 订阅
    • 修复 HTTP 服务允许重复创建的问题
    • 修改更新检查服务器
    • 还原部分原始函数
    • 修复 B 站关注和直播推送失效
    • 修复群组、私聊戳一戳报错
    • 兼容 ws-plugin 的 at 操作和错误提示
    • 删除模板函数 link，请使用 join 代替
    • HTTP 请求增加 DDBOT_REQ_TIMEOUT、DDBOT_REQ_RETRY 设置
      • DDBOT_REQ_TIMEOUT 默认 15s，不支持设为 0
      • DDBOT_REQ_RETRY 默认 0，可设为 3、5 等
    • 为 B 站直播推送模板增加直播分区变量（area_name、parent_area_name）
    • 支持自定义 B 站动态推送模板（notify.group.bilibili.news.tmpl，变量 .dynamic）
    • 支持自定义私聊无效指令触发模板（command.private.unknown_cmd_tips.tmpl）
    • 新增群文件上传事件并支持自定义模板（trigger.group.upload.tmpl）
    • 新增 BOT 离线通知模板（notify.bot.offline.tmpl，需启用心跳上报 + cooldown）
    • 新增模板函数：downloadFile、lsDir、getEleType、toJson

    2025-03-31 0.3.8 (Wsa)

    • 修复群文件上传事件导致的消息处理错误
    • 将动态相关图片接口恢复（下载并调整大小后发送）
    • 将模板中所有媒体传输方式改为由 BOT 实现直接处理
    • 调整以 url 形式投递的媒体文件超时时间为 120s
    • 增加多个媒体类型的发送支持（视频/音频/任意文件，支持 Url/Base64/localPath）
    • 新增模板函数：remoteDownloadFile、loop

    2025-03-23 0.3.7 (Wsa)

    • 更改关注列表过长无法输出的修复方式
    • 修复 Youtube 直播推送失效
    • 支持使用新的 Youtube UID 订阅
    • 为默认配置文件增加 Access Token 字段
    • 支持将 list 模板替换为自定义模板（command.group.list.tmpl）
    • 新增模板函数：getIListJson、outputIList、jsonToDictOrArray

    2025-03-17 0.3.6b (Wsa)
