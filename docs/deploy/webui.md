# Web 管理面板

DDBOT-WSa 的 next-dev 内置一个网页管理面板：不用登录 QQ，在浏览器里就能完成首次初始化、看运行状态、管理订阅与权限、改配置、编辑模板、实时看日志和推送记录。

!!! info "仅在 next-dev 可用"
    该功能由 `webui-embed` 分支开发并已合入 `next-dev`；master / next 不含此功能。

---

## 启用

```yaml
admin:
  enable: true
  addr: "127.0.0.1:15631"   # 监听地址
  token: ""                 # 访问密码；留空时由初始化向导设置
```

重启后访问 `http://127.0.0.1:15631/`。

> `token` 为空时，除初始化向导外的数据接口都会返回 401。监听在非回环地址（如 `0.0.0.0`）时务必设置 `token`。

---

## 首次初始化向导

第一次打开（`token` 为空）进入向导，共 4 步：

1. **设置访问密码** —— 写入 `admin.token`，立即生效，无需重启。
2. **填写 OneBot 连接** —— 模式、监听/反向地址、Access Token（非回环地址必须填 Token，否则会被拒绝）。
3. **选择主题** —— 界面主题，存在浏览器本地。
4. **确认** —— 完成页给出后续操作指引。

> 出于防冒用的考虑，向导只接受**服务器本机**（`127.0.0.1` / `localhost`）访问；远程部署时先在本机完成，或建隧道 `ssh -L 15631:127.0.0.1:15631 user@server`。初始化完成后，远程访问不再受限。

## 面板能做什么

左侧 5 个页面。

### 仪表盘

运行状态、OneBot 连接状态、订阅数量概览。

### 订阅

以扁平表格列出本 BOT 的全部订阅（平台 / ID / 名称 / 群号 / 类型），支持按（平台, ID, 群号）新增 / 删除订阅，编辑时勾选或取消勾选该对象的订阅类型（勾选=添加、取消=移除）。按平台的订阅数量汇总在仪表盘。

单条订阅的触发条件、@全体、过滤等目前只能用群内 `/config` 命令，面板未提供入口。

### 配置

分 7 个 tab，覆盖绝大部分配置项，改完直接保存生效（`logLevel`、`websocket.*`、`proxy.type`、`qq-logs.enable`、`imagePool.type` 例外，它们在启动时读取，需要重启 BOT）：

| Tab | 能改什么 |
|-----|---------|
| **基础** | 命令前缀、进群自动改名、断线后动作、离线消息缓存（开关 + 有效期）；推送发射间隔、并行推送数量、大通知分段阈值 |
| **网络** | OneBot：模式（正向 / 反向）、监听地址、反向地址、Access Token；代理（`proxy.type`）；Telegram 开关 |
| **平台** | **按平台分卡片**，每个平台可**单独启停**。可改各平台账号凭据、轮询间隔、只在开播时推送、以及平台专属项：B 站的图片合并模式 / 动态解析 / 安全分析 / 关注策略（`unsub`、`hiddenSub`、`disableSub`、粉丝门槛），微博的运行模式 / 扫码 / 自动刷新 / API 模式 / Cookie 告警，推特的运行模式 / 转推全文 / User-Agent / API 凭据 / **自动翻译**，以及 ACFun、抖音、小红书、Twitch、TwitCasting、小黑盒、斗鱼、虎牙、YouTube |
| **系统** | 日志级别、QQ 日志、模板总开关、图片池类型 |
| **权限** | 管理员总览、增删管理员、群管理员、静默（silence）、黑名单、命令开关（全局 / 本群） |
| **模板** | 列出全部模板、查看内容、在线编辑、**语法校验**、示例数据**实时预览**、恢复默认 |
| **高级** | 直接编辑完整 JSON（合并写入，未列出的键保持不变） |

> 启停平台用 `platform.<site>.enable`：停用后该平台**完全停止轮询（不请求 API、不产生事件）、也不再推送**；订阅数据与队列条目保留，重新启用后自动继续。

### 实时日志

日志实时流（SSE），不用去服务器上 `tail`。

### 推送记录

看最近推送了什么（实时流 + 历史查询），记录由 buntdb 持久化，保留 30 天。

## 和群内命令的关系

两套入口，管理的是**同一份配置**。日常单个操作（`/watch`、`/config`）用[群内命令](../commands/index.md)更快；批量查看、跨群管理、编辑模板和翻日志用面板更顺手。

## 常见问题

**打不开页面？**
确认 `admin.enable: true` 且已重启；核对访问的地址端口与 `admin.addr` 一致。DDBOT 跑在其他机器/容器时，`127.0.0.1` 指那台机器的本机，需要在同机访问或用反向代理。

**忘记密码？**
清空 `application.yaml` 里的 `admin.token` 后重启，会重新进入初始化向导。

**改了密码要重启吗？**
在向导里设置是立即生效的；直接改 `application.yaml` 里的 `admin.token`（或 `websocket.token`）则需要重启。

**凭据会明文显示吗？**
不会。读取配置时凭据字段一律显示为 `***REDACTED***`。

要改凭据：**平台类**（B 站 SESSDATA/bili_jct、微博 SUB、推特 ct0、抖音 sessionId、小红书 a1 等）可以直接在「平台」tab 里填新值覆盖，留空表示保持不变；但 `websocket.token` 与 `admin.token` 属于后端保护键，**面板不能修改**，需直接编辑 `application.yaml`（`admin.token` 也可重新走初始化向导）。
