# 娱乐命令

DDBOT 的娱乐命令，多为日常使用的小功能。

---

## `/roll` - 随机数

| 默认权限 | 默认启用 | 可禁用 |
|---------|---------|--------|
| 所有人 | 是 | 是 |

生成随机数，或从多个选项中随机选一个。

### 生成随机数

```
/roll                  # 1~100
/roll 10               # 1~10
/roll 100-200          # 100~200
```

### 随机选择

```
/roll 画画 不画 明天再画
```

---

## `/签到` - 每日签到

| 默认权限 | 默认启用 | 可禁用 |
|---------|---------|--------|
| 所有人 | 是 | 是 |

每天可签到 1 次，获得 1 积分。

```
/签到
```

!!! note "积分用途"
    目前积分暂无其他用处，后续可能扩展。可通过模板函数 `getScore`/`addScore` 等自定义积分玩法。

可自定义签到回复，见 [命令模板](../template/command-tmpl.md)。

## `/倒放` - gif 倒放

| 默认权限 | 默认启用 | 可禁用 |
|---------|---------|--------|
| 所有人 | 是 | 是 |

只对 gif 生效，生成倒放的 gif。

### 触发方式

**方式一：带图片**

```
/倒放 [图片]
```

**方式二：回复图片消息**

```
【回复一条图片消息】/倒放
```

!!! note "手机端推荐用方式二"
    手机端发图片命令不方便，回复触发更顺手。

## `/色图` - 随机图片

| 默认权限 | 默认启用 | 可禁用 |
|---------|---------|--------|
| 所有人 | **否** | 是 |

!!! warning "默认关闭"
    该命令默认禁用，需用 `/enable 色图` 开启后才能使用。

返回 p 站图片（NSFW 但非 R18）。

```
/色图
```

!!! note "限制"
    由于该功能曾有失控趋势，现在**不能指定数量和图片 tag**。

需要配置图片池，见 [代理与图片池](../config/proxy-imagepool.md)。

---
